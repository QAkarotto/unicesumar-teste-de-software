# Evidências da execução

Guarde nesta pasta as evidências reais geradas no seu computador.

Sugestão de nomes:

- `status-local.png` — página `http://localhost:3000/status`
- `cenario1-terminal.png` — resumo final do cenário de 1 VU
- `cenario2-terminal.png` — resumo final do cenário progressivo
- `cenario1-summary.json` — resumo estruturado exportado pelo k6
- `cenario2-summary.json` — resumo estruturado exportado pelo k6

Não substitua evidências por imagens ilustrativas nem invente resultados.
