# Futuros testes Web

Adicione aqui arquivos `*.spec.ts` com a fixture `page` do Playwright.
O projeto `web` já está configurado para Chromium e aceita `WEB_BASE_URL`.
Antes de executá-lo, instale o navegador com `npx playwright install chromium`.
Execute com `npm run test:web`. Enquanto não houver testes, esse comando informa
`No tests found`; nenhum teste fictício foi adicionado.
