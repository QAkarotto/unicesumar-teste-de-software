# Testes Web

Esta pasta está configurada no projeto `web` do Playwright e reservada para os futuros testes da aplicação Web.

Quando houver testes Web, instale o Chromium com `npx playwright install chromium`. Defina `WEB_BASE_URL` para o endereço da aplicação e execute `npm run test:web`. O comando falha enquanto esta pasta não contiver testes.
