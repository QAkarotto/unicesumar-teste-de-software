## Testes de performace

## Q1
    O teste funcional verifica se o sistema é utilizavel/funcional.
    Ja o teste de carga assume que funciona e verfica como ele se comporta com carga alta de muitos usuarios fazendo varias requisições

## Q2
    Cada VU simula um usuario fazendo requisições, quanto mais VU no mesmo teste mais carga vai ter por conta das suas requisições simultâneas

## Q3
    check → avalia cada etapa/requisição (granular), só registra ✓/✗
    threshold → avalia o geral/agregado do teste, e reprova se não bater o limite

## Q4
```

iterations
```

Quantas vezes o default function rodou no total

## Q5
o p95 é o valor de tempo abaixo do qual 95% das requisições responderam; os 5% acima são as mais lentas, o que ajuda a identificar gargalos do sistema.
